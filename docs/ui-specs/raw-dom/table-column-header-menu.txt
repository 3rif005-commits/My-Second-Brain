NOTES / CORRECTIONS TO THE PLAN
- The plan guessed "rename, edit property, filter, sort asc/desc, hide, duplicate,
  insert left, insert right, wrap, freeze, delete + a nested type picker".
  Close, but the real labels differ and two rows were missed:
    * "Change type", not "Edit property".
    * "Unwrap content" — a TOGGLE label showing the inverse of current state
      (content is currently wrapped, so the action offered is to unwrap). Our spec
      must render the label from state, not a static "Wrap".
    * "Calculate" — a sub-panel, not in the plan's list at all. Column
      calculations are reachable from the HEADER menu as well as the footer row.
    * "AI Autofill" — not in the plan's list.
    * "Group" is a plain row here (no chevron) though Group is a whole panel
      elsewhere; presumably it groups by this property immediately.
    * "Filter" and "Group" have no chevron; "Sort", "Calculate", "Change type"
      and "AI Autofill" do.
- "Duplicate property" appears greyed. Unverified why — possibly disabled on a
  brand-new/empty property, or a rendering artifact. MUST be re-checked on a
  populated property before the spec claims a disabled state.
- No "Edit property" row: the rename field + "Change type" together do the job
  the plan assumed one "Edit property" panel would.
