*** CORRECTIONS TO THE PLANNED SPEC INDEX ***
1. Filter and Sort are TOP-LEVEL TOOLBAR BUTTONS, not rows inside a ··· menu.
   The toolbar is: Filter · Sort · Automations · AI Autofill · Search · Settings.
   Our DatabaseShell has none of these six.
2. There is no "···" in the view toolbar at all — the equivalent is "Settings",
   and it opens a sidebar (see view-settings-sidebar.txt).
3. "Add icon" / "Add cover" / "Add description" are three separate always-present
   buttons on an empty database, not hover-revealed. Confirm on a NON-empty one:
   they may be hover-only once the database has content.
4. The database title is a `textbox` with a placeholder, i.e. edit-in-place with no
   explicit "rename" affordance. Ours is a static <h1> (DatabaseShell.tsx:388).
5. "New" + "More add options" confirms the split-button shape §12 assumed.
6. The empty state's body renders a single "New page" placeholder row — NOT an
   empty-state message. Our TableView renders "No rows yet." (TableView.tsx:816).
