*** RESOLVES THE OPEN QUESTION: the sidebar PUSHES, it does not fly out ***

  Clicking "Property visibility" REPLACED the sidebar's contents. The new panel
  has a BACK ARROW (←) at its top left, beside the panel title, with the × close
  still at the top right.

  So Notion uses BOTH navigation models, chosen by host surface:
    - column header menu (a popover)  → adjacent FLYOUTS, parent stays visible
    - config sidebar (docked panel)   → PUSH/POP with a back arrow

  `MenuList` therefore needs both modes as an explicit option. Neither is "the"
  Notion pattern. Our own TemplateManager/AutomationManager already do push/pop,
  which matches the sidebar half.
