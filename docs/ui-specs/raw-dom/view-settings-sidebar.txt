NOTES
- Filter / Sort / Group appear BOTH here and as top-level toolbar buttons.
  Two entry points to the same panel; the spec must cover both.
- "Property visibility" carries a COUNT as its right-side value, not a name.
- The "View settings" vs "Data source settings" split mirrors Notion's post-2025
  database/data-source model, which our backend already implements
  (db_databases -> db_data_sources). Our UI has no such split today.
- Section dividers / icons: take from screenshot 18.
- Captured on an empty database. Re-capture on the fixture to confirm no rows
  appear/disappear with data present.
