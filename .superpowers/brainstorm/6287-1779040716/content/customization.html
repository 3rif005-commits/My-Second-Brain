How do you customize the agent's behavior?

You said "give it rules" and "add skills the user can configure". Here are four shapes that can take. They differ in how much structure the user manages.

📝

A · Single persona prompt

One big textbox in Settings. "You are an exam-prep coach. Use Socratic method. Always cite notes." Applies to every AI call. Simple. Limited.

Settings → AI persona → [edit text]
🎭

B · Named agent presets

Multiple agents, each with its own prompt + tool subset + model. Switch with a dropdown. "Coach", "Brainstormer", "Citation Checker". Like Custom GPTs.

Agents → New → name, prompt, tools, model
🧩

C · Composable skills

Library of small skill files, each: name + description + body. AI loads them on demand based on description match. Same shape as Claude Code skills. Shareable, version-controlled.

skills/study-plan.md ← name, when-to-use, body
🪄

D · Agents made of skills

Both layers. User defines named agents (B); each agent composes a set of skills (C); skills can be re-used across agents. Most flexible, most concepts to learn.

Coach = persona + [socratic, citations, mastery] skills

My instinct: C (composable skills) matches what you already know from Claude Code, and gets 90% of D without the agent-management UI overhead. But it depends how many distinct "modes" you actually use.
