Where does the model run?

L4 (agent + tool-use) needs a model smart enough to call tools reliably. Gemma 4 E2B is borderline for that. Pick the speed-vs-offline tradeoff.

☁️

A · Cloud-primary

Big model in the cloud, always. Claude / Nemotron / GPT-4 — fast tool-use, smart skills, low latency. Tablet only for true offline.

⚡ First token: ~300ms
🧠 Reliable tool-use, multi-step agents
💸 Cost or rate limits
🌐 Needs internet (offline = fallback to tablet)
📱

B · Tablet-primary

Gemma 4 E2B on NPU, always. Pure offline, private. Slower (8–15 tok/s) and tool-use is brittle on a small model — you'd have to constrain skills to single-step.

⚡ First token: ~500ms (cold ~3s)
⚠️ Tool-use brittle, multi-step unreliable
🔒 Fully offline, private
💚 Free
🪜

C · Tiered routing per task

Right model for the job. Quick rewrites & simple Q&A → tablet. Agent loops, multi-step skills, ingest → cloud. SmartRouter decides per call. Each tool/skill declares its tier.

⚡ Fast common-case, smart hard-case
🧠 Tool-use only when needed
🛠️ Most complexity to maintain
🔌 Graceful when tablet OR cloud is down
⚡

D · Adaptive escalation

Start fast, escalate if needed. Tablet streams first sentence instantly. If user follows up or asks for tools, escalate silently to cloud mid-stream. User never waits on a cold-start.

⚡ Always instant first token
🧠 Cloud joins when the question gets hard
🤔 Hard to make seamless (model switch mid-stream)
⚠️ Risk of identity inconsistency

My recommendation: C (tiered). You already have a SmartRouter — extend it. Cloud handles agent/skill/ingest (rare, complex). Tablet handles inline rewrites and quick chat (frequent, simple). D is sexier but the mid-stream model switch is a UX trap.
