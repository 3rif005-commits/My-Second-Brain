How deep should the AI reach into your brain?

Each level is a strict superset of the one above. Pick the upper bound — we can ship lower levels first and add the rest later.

👁️

L1 — Read & cite

What you have today, polished. AI reads your notes, answers questions, cites with deep links. Cannot modify anything.

✅ search_brain
✅ get_note
❌ no writing
❌ no creating
✍️

L2 — Read + write current note

The inline /ai story. AI can insert blocks, rewrite a paragraph you selected, generate an interactive block. Bounded to the note you're in.

✅ L1 +
✅ insert_block / replace_block
✅ generate interactive HTML
❌ can't touch other notes
🧠

L3 — Full brain operator

Co-author across the whole brain. AI can create new notes, organize collections, set mastery, link notes together. Multi-step: "summarize my AI notes into a new study plan".

✅ L2 +
✅ create_note / move_note
✅ set_mastery / link_notes
✅ multi-step tool calls
🌐

L4 — L3 + external MCP servers

Brain talks to the world. Internal AI plugs into other MCP servers you connect (web search, Gmail, Calendar, GitHub). External AI like Claude Desktop already talks to your brain via MCP — this makes it bidirectional.

✅ L3 +
✅ MCP client (call external tools)
✅ web search / calendar / etc.
✅ user-configurable connectors

Tip: aim higher than you need today. We can phase the rollout — but the architecture has to support the ceiling from the start.
