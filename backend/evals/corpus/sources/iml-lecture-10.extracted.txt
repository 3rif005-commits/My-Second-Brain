## The "No Teacher" Principle
■ Scenario
• An agent explores an unknown environment  • No instructions, no map  • Only feedback signals
■ Feedback signals :
• Warmer → small positive reward (+) • Colder → small negative reward (−)
■ Outcomes
• Candy → large positive reward (goal) • Lemon → large negative reward (penalty)
7
The "No Teacher" Principle
■ Learning process
• The agent takes actions (moves)  • Receives rewards or penalties  • Gradually learns which actions lead to better outcomes
■ Insight
• No correct path is given • The agent improves by accumulating rewards over time • This is the core of Reinforcement Learning

## Q-Learning
■ The agent takes the decision  to go down
■ The agent transitions from  state S1 to S4
■ In doing so, the agent  receives a reward
■ Let’s calculate the  observed  Q-value
19
Observed Q-value : the Bellman Equation
Q(S1, down) _observed = R(S4) + γ max
_a Q(S4, a)
■ The agent is in state S1
■ It takes action down
■ It arrives in state S4
■ It receives reward R(S4) for arriving there
■ Discount factor  γ  :
• how much the robot cares about future rewards compared to immediate  rewards. • γ  = 0  : Robot only cares about the  immediate  reward. Future doesn't matter. • γ  = 0.5  : Future rewards matter half as much as immediate rewards • γ  = 0.9  : Future rewards matter, but slightly less than today's rewards. • γ  = 1  : Robot values future rewards  equally  to immediate rewards.

## Observed Q-value : the Temporal Difference Error
Q(S1, down) _observed = R(S4) + γ  max
a Q(S4, a)
Q(S1, down) _observed = −1 + 0.1 × 1.5 =  −0. 85
■ Q(S1, down) _observed = −0.85 but  Q(S1, down)   = 0.75  from the table
■ Temporal Difference Error :
• TDE = Q(S1, down) _observed −Q(S1, down) _expected ■ In out example :  TDE = −1.6
21
Observed Q-value : Update Rule
■ Now we update the table based on the update rule :
Q(S1, down ) = Q(S1, down) _expected + α × TDE
■ Where :
• α  : learning rate/step size  • α  : How much we update the Q-value at each time step.
■ For our example :
QS1, down= 0.75 + 0.1 ×   −1.6   = 0.59

## Why One Episode Is Not Enough
33
■ After just one attempt, the robot's Q-values are still wrong or unstable.
■ Look at Q(S1, Down) after one episode = 0.59
■ But is this the true value? No! Because:
• The robot hasn't discovered the path to S9 yet • It hasn't experienced the +10 reward • It only saw negative rewards so far (-1, -2, -1)
Why Multiple Episodes Are Needed
34
■ Each episode gives the robot more experience. With each episode:
1. The robot might try different actions (exploration) 2. It might discover better paths 3. It updates Q-values closer to the truth 4. Eventually, Q-values converge (stop changing much)
  After many episodes, the Q-value stops changing much.
That's when learning is done.
  When Q-values stop changing, the robot has learned the optimal policy:
from any state, it knows exactly which action leads to the highest total
reward.
