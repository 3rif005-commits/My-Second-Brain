         The Intuitive Definition

                      action to take) based on rewards and punishments received
                      from the environment.

The "No Teacher" Principle

 ■   Scenario
      •   An agent explores an unknown environment
      •   No instructions, no map
      •   Only feedback signals

 ■   Feedback signals :
      •   Warmer → small positive reward (+)
      •   Colder → small negative reward (−)
 ■   Outcomes
      •   Candy → large positive reward (goal)
      •   Lemon → large negative reward (penalty)

                                                                   7

The "No Teacher" Principle

 ■   Learning process
      •   The agent takes actions (moves)
      •   Receives rewards or penalties
      •   Gradually learns which actions lead to better outcomes

 ■   Insight
      •   No correct path is given
      •   The agent improves by accumulating rewards over time
      •   This is the core of Reinforcement Learning

The Exploration-Exploitation Dilemma

 ■   « Should I do what I already know works (exploit), or try
     something new that might be better (explore)? »

 ■   Exploitation = Greedy choice (highest known Q-value)
 ■   Exploration = Random choice (to discover better paths)

Observed Q-value : the Bellman Equation

                  Q(S1, down)              = R(S4) + γ max Q(S4, a)
 ■   The agent is in state S1
 ■   It takes action down
 ■   It arrives in state S4
 ■   It receives reward R(S4) for arriving there

 ■   Discount factor γ :
          •   how much the robot cares about future rewards compared to immediate
              rewards.
          •   γ = 0 : Robot only cares about the immediate reward. Future doesn't matter.
          •   γ = 0.5 : Future rewards matter half as much as immediate rewards
          •   γ = 0.9 : Future rewards matter, but slightly less than today's rewards.
          •   γ = 1 : Robot values future rewards equally to immediate rewards.

What is an Episode?

 ■   An episode is one complete run from start to goal (or failure).

 ■   In our previous grid:
      •    Episode starts: Robot at some starting cell (S1, or randomly chosen)
      •    Episode ends: Robot reaches S9 (+10) or maybe hits S8 (-10)

 ■   We Walked Through One Partial Episode
               S1 --Down--> S4 --Right--> S5 --Right--> S6 ...

 ■   But the episode is not even finished! The robot hasn't reached S8/S9 yet.

Why One Episode Is Not Enough

 ■   After just one attempt, the robot's Q-values are still wrong or unstable.

 ■   Look at Q(S1, Down) after one episode = 0.59
 ■   But is this the true value? No! Because:

      •        The robot hasn't discovered the path to S9 yet
      •        It hasn't experienced the +10 reward
      •        It only saw negative rewards so far (-1, -2, -1)

                                                                                 33

Why Multiple Episodes Are Needed

 ■   Each episode gives the robot more experience. With each episode:

      1.       The robot might try different actions (exploration)
      2.       It might discover better paths
      3.       It updates Q-values closer to the truth
      4.       Eventually, Q-values converge (stop changing much)

                 After many episodes, the Q-value stops changing much.
                             That's when learning is done.

    When Q-values stop changing, the robot has learned the optimal policy:
     from any state, it knows exactly which action leads to the highest total
                                     reward.
