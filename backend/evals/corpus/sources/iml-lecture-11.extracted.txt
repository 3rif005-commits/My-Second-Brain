What is Bias in ML?
■ Algorithmic bias : systematic, unfair discrimination in model  outputs that creates different outcomes for different groups,  where group membership should not matter.
■ Key nuance (important):
■ Not all differences are bias
■ Bias = difference + unjustified + harmful

■ Where bias enters the pipeline
past society            data collected      labels defined       model design

Historical Bias
■ Historical bias : the world is unfair, data remembers
■ Definition  : Past social inequalities reflected in training data.
■ Exemple :
■ Loan model trained on past approvals learns that certain zip  codes (historically redlined) have higher default rates, even if  current residents are equally creditworthy.
8
[page 5]
05 /1 2 /2 0 2 6
5
## Representation Bias
■ Representation bias : missing voices = blind spots
■ Definition :  Training data does not reflect the real population.
■ Example
■ Medical image model trained mostly on fair-skin photos →  performs poorly on darker skin tones.
9
Measurement Bias
■ Measurement bias : wrong proxy, wrong conclusion
■ Definition : Features or labels are systematically different across  groups.
■ Example
■ Using healthcare costs as proxy for "health need." Lower access  to care  -> lower recorded costs  -> model thinks group needs less  care.
10
[page 6]

## Aggregation Bias
■ Aggregation bias : one-size-fits-all fails
■ Definition: Forcing same model requirements on groups with  different base rates.
■ Example
■ Single recidivism model for two neighborhoods with different  crime rates and policing intensity. Looks "accurate" on average,  wrong for both.
11

## The goal — automate resume screening
The idea:
■ Use machine learning to screen resumes
■ Same way Amazon recommends products
■ Train the algorithm on past resumes and hiring decisions
■ Let it learn which resumes led to hires
■ Then let it rank new resumes automatically

## Type of Bias – Historical Bias
■ Follow patterns from history
■ Apply them to new resumes
■ Hidden patterns included unfair ones
■ Amazon engineers did NOT program the AI to discriminate
■ The AI learned it by itself
■ Pattern it saw: Most successful past hires = men
■ So resumes like those  -> higher score
■ To the machine, it was just math. Not intention.
  This is called:  Algorithmic bias  or  Statistical discrimination
23
What Amazon Did
Timeline:
■ 2014: Amazon starts building the tool
■ 2015: Internal team discovers gender bias
■ 2017: Amazon discontinues the tool
■ Engineers tried to fix it:
• Removed gender-related words • Adjusted the model • Ran new tests • The bias kept coming back (through hidden correlations)

## Type of Bias – Measurement Bias
■ Features or labels are systematically different across groups.
Apply to Optum:
■ Label: Past healthcare costs (used as proxy for health need)
■ Problem: Past costs reflect access, not just need
■ Result: Model learned: low costs → low need (even when need  was high)

## Type of Bias – Representation Bias
Apply to Gender Shades:
■ Training data: 80-86% lighter-skinned faces
■ Problem: Algorithms learned patterns from mostly lighter faces
■ Result: Poor performance on darker-skinned faces (especially  women)

■ IBM: 17.73% error reduction
■ Face++: 30.4% error reduction (biggest improvement)

## Type of Bias
■ Not a simple "bias type" : this is a trade-off
■ ProPublica’s claim : COMPAS is racially biased
■ Nothpoint’s defense : COMPAS is equally accurate for both  groups
43
Fairness
■ Both right but by different fairness metrics !
■ Different fairness metrics can conflict
■ Choosing a metric means choosing whose errors you prioritize
■ No algorithm can satisfy all definitions of fairness simultaneously

Deeper Problem
■ Base rate = actual re-offending rate in the population
■ White defendants ~35%
■ Black defendants   ~52%
■ When base rates differ across groups, it is  mathematically  impossible  to have equal false positive rates AND equal false  negative rates simultaneously.
