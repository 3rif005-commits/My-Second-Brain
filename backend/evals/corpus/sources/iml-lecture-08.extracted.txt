Motivation & Ensemble Idea
■ Definition of Ensembles :
• Machine learning technique that combines multiple models to  make better predictions • Each model is called a base learner • Output is a combination (average, vote) of base predictions

## Why Use Ensembles ?
1. Single algorithms are not fixed
■ Even one training algorithm produces different models  depending on :
• Training data (different split or subsets) • Hyperparameters (learning rate, tree depth) • Random initialisations
2. Consequence of variability
■ Different models from the same algorithm will have different:
• Bias : systematic error from oversimplification • Variance : sensitivity to small changes in training data • Irreducible error : noise inherent in the data
5
Why Use Ensembles ?
3. Ensemble solution
■ By combining several diverse models, ensemble methods can:
• Reduce overall error • Preserve each model’s strengths • Often lower variance without increasing bias too much

## Simple Numeric Illustration
■ Predicting a  small  house (true price = $200K):
■ 3 models :
• Tree A (specialist on small ) : $205k • Tree B (specialist on large) : $260k • Tree C (generalist) : $220k • Ensemble average :  $228k
■ The ensemble error ($28K) is:
■ Worse than Tree A alone ($5K error)
■ But much better than Tree B alone ($60K error)
■ And much more stable across different house sizes than any  single tree
7
Advantages
■ Greater diversity → More accurate ensemble
■ Under-regularized (overfitting) models work well in ensembles
• Overfitting models are  high variance, low bias . Combine diverse  overfitting models → variance cancels, low bias remains
■ Alternative to dimensionality reduction

## Types of Ensemble Models
  Two Branches of Ensemble Learning :
Parallel vs. Sequential Methods
Parallel
■ Train each base learner  independently of all others
■ Training can happen  simultaneously
■ Results combined at the end
■ Order of training irrelevant
Ex : Random Forest
Sequential
■ New model learns from the  mistakes of the previous one
■ Each new model fixes prior  mistakes.
■ Train in stages
■ Order matters critically
Ex : Gradient Boosting

## Ensemble Techniques
■ Three most popular :
• Bagging  • Boosting  • Stacking
■ Other ensemble techniques include:
• Blending • Weighted average ensembles • Voting ensembles • Super ensembles
11
Bagging
■ Type:  Parallel + Homogeneous
■ How it works :
• Create multiple random samples of the training data • Train the same base algorithm on each sample independently • Combine predictions by voting (classification) or averaging  (regression)
■ Famous algorithm : Random Forest

## Boosting
■ Type: Sequential + Homogeneous
■ How it works:
• Train first weak model on original data • Identify which examples it got wrong • Train next model to focus on those mistakes • Repeat for many stages • Combine all models with weighted voting
■ Famous algorithms: AdaBoost, Gradient Boosting, XGBoost
13
Stacking
■ Type: Typically Parallel + Heterogeneous
■ How it works:
• Train multiple different base models (SVM, decision tree, neural  network) on the same data • All base models make predictions • A separate meta-model learns how to best combine their  predictions
■ Famous algorithm: SuperLearner

## Why Random Forest Needs Diversity – Not Identical Trees
■ Random forest needs diversity, not identical trees
■ The problem with identical trees:
■ If we take the same application (same set of features)
■ Build trees using the same parameters
■ Every tree will be exactly the same
■ Five identical trees each output the same probability of default
■ This is pointless : no benefit from combining them
The Random Forest solution – inject diversity:
■ Each tree gets a slightly different version of the data
■ With 10 total features, each tree might only get 7 of them
■ Different trees get different subsets of features
■ Each tree sees a different “perspective” on the same application
■ The result:
• Trees make different predictions • Errors cancel out • Ensemble becomes stronger than any single tree

## Tuning Number of Trees
■ “n_estimators”  is a hyparameter that controls the number of trees
■ For the credit score example :
• The AUC increases sharply  • After n_estimators=50, no  increase in performance • Useless to train more than 50  trees in this case
Tuning Trees Depth
■ “max_depth”  is a hyparameter that controls the max depth of a  single tree
■ For the credit score example :
• Depth 10 wins • Depth 15 slightly worse deeper  is not always better • Depth 5 too shallow • Use 150+ trees for depth 10

## Weak Learner – The building block
■ A weak learner is a model that performs just slightly better than  random guessing.
■ Example :
• Tree with only 1 split (2 leaves) • Accuracy : 55-65% on binary classification • Using it on its own : not very useful
■ A weak learner make many mistakes  by design
Strong Learner – Final goal
■ A strong learner is a model that achieves  high accuracy  (90– 95%+).
■ Example :
• Deep decision tree • Well-tuned neural network  • Gradient Boosting's final output
  Building a strong learner  directly  is hard. Deep trees overfit.  Neural networks need lots of tuning.

## Why Not Start Strong?
■ Gradient Boosting Uses Weak Trees (Depth=3–5)
■ If first tree is too strong (depth=15):
• Makes very few errors • Nothing meaningful left for next trees • Overfits immediately • Can't correct gradually
■ If first tree is weak (depth=3):
• Makes  simple, predictable errors • Next tree easily learns those errors • Each tree adds a  small improvement • Learning rate controls the step size
Learning Rate – The Problem
■ What if the 1st tree is slightly/strongly wrong ?
■ Problem :
• Adding the  full  tree's prediction can be too aggressive. One bad  tree ruins everything.

## Learning Rate – The Solution
■ The learning rate ( η)  allows to take small steps
■ It controls how much of each tree's correction we add.
■ New prediction = Old prediction +  η  × (Tree's correction)
■ η  between 0 and 1
■ Previous example with  η= 0.5
High vs Low Learning Rate
■ In gradient boosting, typical values between 0.01-0.3 depending  on the algorithm

## Random Forest vs Gradient Boosting
Mechanism Comparison
■ Random Forest:
• Train many trees on  different random samples  (bagging)  • Predict =  average or majority vote • Trees don’t talk to each other
■ Gradient Boosting:
• Train trees  sequentially • Each tree  learns errors  of previous trees  • Predict =  sum of tree predictions

## Mechanism Comparison
Intuition / Analogy
■ Random Forest:
• Asks many independent experts and average their answers →  reduces mistakes by averaging
■ Gradient Boosting:
• Asks an expert, see where they are wrong, then next expert  corrects the mistakes → builds stronger model gradually
