# Prompts Workspace

Drop LLM prompt drafts here. Each prompt gets its own file.

## Naming convention
`[phase]-[purpose].md`

Examples:
- `p2-mastery-guide-generation.md`   — the main ingestion prompt for Phase 2
- `p3-tutor-system-prompt.md`        — the context-augmented tutor prompt
- `p3-metadata-extraction.md`        — auto-extract title/topics from ingested content
